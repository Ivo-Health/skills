Move visit reassignment rules onto the visit

Domain model Strong Clinical logic: needs clinical-safety

Problem

The rule that a completed visit cannot be reassigned is checked in three places, and one of them is missing a status.

Evidence

  • Services/VisitService.cs:84 VisitService.ReassignAsync
  • Components/Pages/Rota.razor.cs:132 Rota.OnReassign
  • Controllers/VisitsController.cs:57 VisitsController.Reassign

Direction

Give Visit one method that applies the rule and returns a result. Callers ask the visit instead of checking its status.

Gains

  • Callers: one call, no status checks to copy.
  • Maintainers: the rule changes in one place.
  • Tests: the rule is tested on Visit with plain values.
